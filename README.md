# My Counter

A simple and interactive **JavaScript counter application** that allows you to increase, decrease, and reset a numeric value with smooth animations. Designed with clean UI and minimal code structure.

---

## ✨ Features
- Increment counter (+)
- Decrement counter (–)
- Reset counter (0)
- Smooth "pop" animation on value change
- Simple, responsive layout
- Pure HTML, CSS, and JavaScript — no libraries

## 🧠 How It Works

### JavaScript Logic
- `increase()` adds 1 to the current counter.
- `decrease()` subtracts 1 but never goes below 0.
- `reset()` sets the value back to 0.
- Every action triggers an animation (`pop` class).

### Event Listeners
- `.counterIncrese` → increase button  
- `.counterDecrease` → decrease button  
- `.counterResetButton` → reset button
